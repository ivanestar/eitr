# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.4.x   | Yes       |
| < 0.4.0 | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in EITR, please report it privately:

- **Email:** [inestar@yahoo.com](mailto:inestar@yahoo.com)
- **Subject:** `[SECURITY] EITR Vulnerability Report`

Please include:

1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Affected versions and environments.

We will acknowledge receipt within 48 hours and work on a prompt resolution. Please do not open public GitHub issues for security vulnerabilities.
